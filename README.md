# CloudyCat

Working title **Moth**: a calm 3D platform-puzzler about a small cat made of cloud, wandering a hand-painted valley and waking its sleeping spirits.

- `docs/concept.html`: M0 concept (cat, moves, levels, art direction, build plan).
- `docs/CHARACTER.md`: character design brief for the cloud cat.
- `study/`: real-time 3D look study of the cat. `index.html` is the built page; edit `template.html` and `designs.mjs`.
